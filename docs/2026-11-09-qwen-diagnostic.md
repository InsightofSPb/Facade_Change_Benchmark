# Bbox и два диагностических запроса Qwen — 2026-11-09

Основание — сообщение владельца о WSL smoke
`runs/2026-11-09-agentic-qwen-prompt-models-002` на базе `54780f2`:
два ответа agent с `[160, 128, 160, 128]`, ошибочная трактовка области как source-only
и расхождение режимов в описании видимого различия. Реальные файлы этого запуска
в Cloud недоступны; их содержимое здесь не объявляется проверенным.

В основной инструкции теперь задано `bbox_xyxy = [left, top, right, bottom]`,
четыре конечных числа в заявленной системе координат, `right > left`, `bottom > top`.
Ошибка в существующем retry содержит исходные координаты, конкретную причину
(в том числе ширину/высоту) и известные границы сетки. Модель может явно выбрать
`localization: null`, сохранив остальные требования к решению и свидетельствам.
Неправильные рамки не исправляются, не расширяются, не переставляются и не заменяются
на null автоматически. Исходные ответы и прежний предел попыток сохраняются.

## Отдельная диагностика сохранённого запуска

`scripts/2026-11-09_qwen_diagnostic.py` использует существующие `ModelPool`, worker,
RunStore, функции координат и журнал прогресса. Основной протокол сравнения не меняется.
Из корня репозитория после `git pull --ff-only` выполните одну команду:

```bash
/home/sasha/miniconda3/envs/change-agentic-rag/bin/python /home/sasha/Facade_Change_Benchmark/scripts/2026-11-09_qwen_diagnostic.py \
  --run /home/sasha/Facade_Change_Benchmark/runs/2026-11-09-agentic-qwen-prompt-models-002 \
  --config /home/sasha/Facade_Change_Benchmark/configs/2026-11-08-agentic-wsl-16k-001.local.json \
  --out /home/sasha/Facade_Change_Benchmark/runs/2026-11-09-qwen-bbox-diagnostic-001
```

Каталог вывода должен быть новым и находиться вне исходного запуска. Скрипт:

1. Строит `visualizations/pair.png` и `fixed_context.png` из сохранённых результатов
   `synthetic-2025`; для каждого исходного final-ответа agent читает `messages.json`
   и создаёт отдельное `agent-message-<index>.png`. Нулевая рамка — контрастный крест
   с подписью `invalid: zero-area bbox`, а не исправленный прямоугольник.
2. Использует RGB-артефакт непосредственно цитируемого evidence ID. Сохранённые
   source/anchor-to-crop преобразования переводят координаты на его фактическую
   сетку; native-координаты не рисуются как crop-координаты. Если RGB, владелец или
   преобразование неоднозначны, изображение не подменяется: причина записывается
   в `visualizations/index.json`. Там же сохранены исходные bbox, перенесённые углы,
   пути, хеши и смещение RGB относительно подписи. Изображения не масштабируются.
3. Выбирает reference/source RGB из начального user-сообщения сохранённого
   `synthetic-2020 / pair`, сверяет evidence ID, роль RGB и хеши артефактов и state.
   Alignment, детекторы, fusion и пересоздание кропов не выполняются. Визуализации
   не передаются модели.
4. Отправляет два независимых user-сообщения: reference/source и reference/reference.
   В каждом только заданная владельцем краткая русская инструкция, метки A/B и два
   изображения; без истории, поддержки, инструментов, примеров или JSON/bbox-схемы.
   Параметры Qwen и бюджеты сверяются с конфигурацией сохранённого запуска.
5. Переиспользует один pool и загруженный Qwen worker между запросами, без кеширования
   ответов. Только штатное техническое восстановление worker может вызвать перезапуск;
   его попытки, расходы, причины и PID остаются в usage/журналах. Дополнительных
   попыток для получения желаемого ответа нет. GPU preflight и локальная загрузка
   весов выполняются прежним worker; чужие процессы не останавливаются.

В новом каталоге находятся `run.json`, конфигурация, source snapshot, `inputs.json`
с путями/хешами, `model_options.json`, `worker_logs/`, `summary.json` и визуализации.
В `reference-source/` и `reference-reference/` сохраняются точный запрос в ModelPool
(`request.json`), полный ответ с checkpoint provenance, processing/generation и usage
(`response.json`), исходный текст (`response.txt`) и измерения (`measurement.json`).
Фактический worker timeout учитывается прежним supervisor и виден в generation/max_time;
первый запрос может включать загрузку модели, второй использует прогретый worker.

Принятый bbox и `common_fraction=1.0` удостоверяют допустимость геометрии,
**не точность локализации изменения**. Эта оговорка есть на каждом изображении.
Два запроса — диагностика конкретного сбоя, не оценка accuracy. До просмотра
реальных ответов улучшение качества не подтверждено.

не выполнялись. Тестовые ответы не являются результатами Qwen.
