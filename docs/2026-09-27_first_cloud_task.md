# Первое задание для Codex Cloud

Ты работаешь в новом репозитории Facade Change Benchmark. Прочитай AGENTS.md и README.md.
Исходные локальные каталоги владельца `/home/sasha/...` недоступны в Cloud.
Не пытайся повторить прежнее задание как локальный аудит LPOSS: нужная начальная логика
уже перенесена сюда, её происхождение описано в docs/2026-09-27_provenance.md.

Цель задачи — проверить основу перед первым локальным запуском на реальных фасадах.

1. Выполни CPU-тесты и demo на новой директории. Зафиксируй команды и фактический результат.
2. Проверь реальный путь данных в коде: COCO → разрешение файлов → манифест → native/proxy
   координаты → общий MAGSAC → расширяемый холст → маски поддержки → отчёт.
   Удели внимание несовпадениям размеров, неоднозначным путям, новым областям,
   ошибкам направления H и несовпадению RGB/BGR. Исправь обнаруженные конкретные ошибки.
3. Посмотри диагностические изображения синтетики. Не выдавай их за оценку реального метода.
4. LoFTR-адаптер пока не проверен с весами. Не скачивай модель автоматически; проверь
   контракт и сформулируй конкретные требования для локального checkpoint и окружения.
5. Сохрани короткий датированный отчёт: что проверено, что исправлено, что остаётся
   проверить локально. Дай точную первую команду построения манифеста владельцу.

Критерий готовности: воспроизводимый CPU-пример проходит, пути запуска понятны,
ограничения описаны честно. Полный benchmark, обучение, новые детекторы и переразметка
COCO не входят в это первое задание. После получения локального summary.txt следующая
задача будет привязана к фактическим проблемам данных и совмещения.
